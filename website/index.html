Engineered for Frictionless Remote Access

Connex strips away the bloat of traditional remote access software, focusing strictly on speed, security, and presentation safety.

Share-Safe Window Privacy

Keep your remote assistance session completely hidden from meeting participants. While you present on Google Meet, Zoom, Microsoft Teams, or Slack, Connex is omitted from the broadcast feed so confidential diagnostics remain strictly on your monitor.

Direct P2P WebRTC

Display frames stream directly between your devices at 30 FPS over end-to-end encrypted DTLS-SRTP data channels with sub-50ms round-trip latency.

Instant Numeric ID & PIN

No registration emails, passwords, or corporate login walls. Every installation generates a 6-digit device ID and a passcode you can rotate at any second.

Native Rust Performance

Compiled natively with Rust and Tauri rather than a heavy Chromium web browser bundle. Launches instantly and consumes under 30 MB of system memory.

Low-Latency Input Sync

Responsive pointer tracking, left/right/middle click support, mouse scroll wheel, and full keyboard shortcut injection transmitted over binary channels.

macOS Tip First-time Launch Setup

Because Connex is an open-source tool without a corporate Apple Developer certificate, macOS Gatekeeper may show: "Connex is damaged and can't be opened." Run this one-time command in Terminal to clear quarantine:

xattr -cr /Applications/Connex.app

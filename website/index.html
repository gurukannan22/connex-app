How Meeting Invisibility Works

Connex leverages native operating system compositor APIs to cleanly exclude its window from all desktop video capture pipelines.

macOS NSWindowSharingNone

Native Quartz Compositor Exclusion

On macOS Silicon & Intel, Connex sets setSharingType: NSWindowSharingNone directly on the NSWindow. The window remains visible and interactive for you on your physical screen, but CoreGraphics and ScreenCaptureKit completely bypass it. Google Meet, Zoom, Microsoft Teams, Slack, and OBS see only whatever is behind the window.

Windows WDA_EXCLUDEFROMCAPTURE

Desktop Window Manager (DWM) Exclusion

On Windows 10 and 11, Connex applies SetWindowDisplayAffinity(hwnd, WDA_EXCLUDEFROMCAPTURE) (0x00000011). DWM instructs the compositor to omit the application from all screen capture surfaces. Meeting software captures transparent or background desktop pixels instead.

Key Capabilities

UltraViewer Simplicity, Built for 2026

Zero bloat, zero account signups, zero server relay lag.

⚡

Ultra-Fast WebRTC P2P

High frame-rate 30 FPS display streaming directly between peers with minimal latency and high compression JPEG encoding.

🛡️

End-to-End Encrypted

All screen frames and remote control inputs are encrypted with DTLS-SRTP. No central servers store or inspect your session.

🎯

Responsive Remote Control

Low latency mouse pointer synchronization, left/right/middle click support, scroll wheel, and full keyboard event injection.

🔑

Instant Numeric ID & Passcode

Every device has a static 6-digit ID and rotatable passcode. No complicated setup, email verification, or registration needed.

🪶

Under 25 MB Memory

Built with Rust and Tauri 2 instead of heavy Electron wrappers. Consumes 90% less RAM and launches in milliseconds.
